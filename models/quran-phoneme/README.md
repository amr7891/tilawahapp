# Quran phoneme model (runs on the phone)

Streaming Zipformer2 CTC phoneme recognizer for Quran recitation (Hafs), by
Muno459 / Quran-Lab (`Muno459/zipformer_p-arabic-v2`, int8 ONNX), as mirrored
unmodified at `swaraadam/quran-phoneme-zipformer`.

`model-io.json` (inputs, outputs and streaming state shapes), `LICENSE`.
